# 刘艺个人主页

这是一个可直接发布到 GitHub Pages 的静态个人主页。

## 文件结构

- `index.html`：网页主体
- `styles.css`：网页样式
- `robots.txt`：搜索引擎访问规则
- `ppt_assets/`：网页使用的图片资源
- `.nojekyll`：让 GitHub Pages 按普通静态站点发布

## GitHub Pages 发布步骤

1. 打开你的 GitHub 仓库。
2. 上传 `index.html`、`styles.css`、`robots.txt`、`.nojekyll`、`README.md` 和 `ppt_assets` 文件夹。
3. 进入仓库 `Settings`。
4. 左侧点击 `Pages`。
5. `Source` 选择 `Deploy from a branch`。
6. `Branch` 选择 `main`，目录选择 `/ (root)`。
7. 点击 `Save`。

发布完成后，GitHub Pages 页面会显示访问地址，通常是：

`https://你的GitHub用户名.github.io/仓库名/`
